    For each processed video, open its labeling page. Mark each detected card instance as Front, Back, or phantom. Add a card_id and optional physical_card_key (for cross-video dedup ground truth). Use the "Add missing card" section for any cards the pipeline missed.

    Then move the video file into tests/fixtures/golden_corpus/<stem>/<stem>.mp4 so the harness can find it.

    {% if video_count > 0 %}

    {% endif %}
  • 3 Run the regression harness {% if any_report %} ✓ Report exists {% else %} Not run yet {% endif %}

    Run the harness against your labeled corpus to generate the first metrics report.

    card-capture harness run  or  make harness

    This writes a JSON + Markdown report to reports/<git-sha>.json.

  • 4 Capture the V3 baseline {% if has_baseline %} ✓ baseline_v3.json exists {% else %} Not captured {% endif %}

    Rename the report from step 3 as the permanent baseline. Every Phase A–F change will compare against this.

    mv reports/<sha>.json reports/baseline_v3.json  or  make baseline

    Once this exists, run card-capture harness run --baseline reports/baseline_v3.json after any pipeline change to see deltas.
