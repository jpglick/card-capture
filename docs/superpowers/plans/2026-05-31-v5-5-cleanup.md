# v5.5.0 Tag & Post-Refactor Cleanup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tag the merged v5.5 state as `v5.5.0`, then remove all cloud / vast.ai / RunPod / Beam / Metaflow / CUDA code, config, scripts, deps, docs, and tests; archive prior-version architecture docs; write a v5.5 architecture document; and bring operator docs in line with the Apple-Silicon-only local workflow.

**Architecture:** Cleanup lands on branch `cleanup/v5.5-post-merge` as eight themed, individually-revertible commits. The `v5.5.0` tag is the only action against `main` and is created first so it marks the exact merged state. Each removal commit must leave `pytest -m "not quarantine"` and `lint-imports` green; if a removal cascades deeper than the surface below, stop and surface it rather than gutting working pipeline code.

**Tech Stack:** Python 3.9+, FastAPI, PyTorch (MPS/CoreML/CPU), SQLite, import-linter, pytest, git.

**Reference spec:** `docs/superpowers/specs/2026-05-31-v5-5-cleanup-design.md`
